# Campus Outbreak

A 2D top-down survival horror action-adventure game built with Pygame.

## Overview
Set in a quarantined university campus during a sudden viral outbreak, you must navigate various department blocks, solve environmental puzzles, fight infected hordes, rescue stranded students, and locate the cure in the secret Research Department.

## Completed Chapters & Modules
- **Campus World & Exploration**: Top-down procedural map with dynamic buildings, roads, and smooth camera tracking.
- **AI Block**: Terminal puzzle decoding, security lockdown, and wave-based survival combat.
- **Mechanical Block**: Heavy machinery hazards, student zombies, and escorting rescued survivors.
- **Library Chapter**: Atmospheric book stacks, survivor NPCs, hidden doors, and elite Faculty Zombies.
